# 项目长期记忆

## 项目概况
- **项目名**：桌面智能灵动岛
- **性质**：武汉理工大学 2025-2026 "信息无限"电子科技文化节·人人卓越工程第三阶段 B选题
- **考核日期**：2026-06-06/07
- **技术方案文档**：`技术方案与分工.md`（v1.0, 2026-05-18）

## 用户角色
- 程铮：项目队长，统筹所有任务，负责 **D角色（小程序+云端）**
- 同时需要协调A(硬件)、B(基础固件)、C(高级固件+AI) 的工作

## 硬件方案
- 主控：ESP32-C3 Super Mini（已有）
- 显示：0.96寸 OLED 128×64 I2C（已有）
- 麦克风：INMP441 I2S（待买）
- 功放+喇叭：PAM8403 + 3W 4Ω（待买）
- 不打板，使用成品板+杜邦线直连
- 外壳：3D打印

## 外壳与3D设计决策（2026-05-20 更新）
- 不打自定义PCB，使用成品板+杜邦线直连
- 核心需求：三维空间排布多块成品板+元器件+连线设计
- 先用铜丝/扎带固定原型，后续可能3D打印外壳（非必须）
- 嘉立创EDA的3D外壳功能不适用（依赖PCB板框，不适合多板组装场景）
- 推荐：Fusion 360 个人免费版（装配体+连线设计）
- 备选：FreeCAD（完全免费开源）
- 3D模型获取：GrabCAD/3Dwhere/Printables/SnapEDA 均有ESP32-C3/INMP441/PAM8403/OLED模型

## 技术栈
- ESP32固件：Arduino框架 C/C++
- 小程序：原生微信小程序 JS+WXML+WXSS
- AI：智谱GLM-4-Flash（云端）+ Ollama qwen2.5:0.5b（本地备用）
- 语音：百度ASR/TTS
- 通信：MQTT（EMQX Cloud）
- 天气：和风天气API
