# 桌面智能灵动岛 — 界面与功能设计

> 版本：v1.0 | 日期：2026-05-22 | 基于技术方案 v1.0

---

## 设计总览

本项目有两个交互端面：
- **OLED 端**：ESP32-C3 驱动的 0.96 寸 OLED（128×64 单色），是设备的"脸"——表情、时间、信息预览、交互反馈
- **网页/小程序端**：微信小程序，是设备的"遥控器"——任务管理、AI对话、番茄钟控制、设备设置

两端通过 MQTT 实时双向同步，共用同一份数据模型。

```
┌─────────────────────────────────────┐
│            OLED 显示端               │
│  ┌───────────────────────────────┐  │
│  │   128 × 64 像素 单色屏幕       │  │
│  │   状态机驱动，6 个核心模式     │  │
│  │   按键切换 + MQTT 远程触发     │  │
│  └───────────────────────────────┘  │
│                  ↕ MQTT              │
│  ┌───────────────────────────────┐  │
│  │         微信小程序端            │  │
│  │   5 个 Tab 页面                │  │
│  │   卡片式 UI，响应式布局        │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

## 二、OLED 核心模式

OLED 端设计为 **6 个核心模式**。CHAT-ROBOT 是中枢——开机默认进入、超时自动返回。

| 模式 | 定位 | 说明 |
|------|------|------|
| **CHAT-ROBOT**（默认） | 机器宠交互 | 开机/超时回到这里，空闲显示表情包，长按C语音→AI思考→显示回复 |
| **CLOCK** | 时钟 | 全屏时间日期 + 天气/任务摘要 |
| **COUNTDOWN** | 倒计时 | 番茄钟专注/休息倒计时，E/F 键调时间 |
| **TODO** | 待办任务 | 显示手机端同步的任务列表，可查看详情、一键启动倒计时 |
| **WEATHER** | 天气 | 今日天气详情 + 未来预报 |
| **SETTINGS** | 设置 | 配网、亮度、音量、超时时间、设备信息 |

**关键设计决策**：
- CHAT-ROBOT 是"家"：开机动画结束 → CHAT-ROBOT，超时无操作 → CHAT-ROBOT（倒计时运行中除外）
- 语音输入、AI 思考、AI 回复 全部是 CHAT-ROBOT 内的子状态
- 任务由手机端创建和同步，OLED 端可查看、标记、一键启动倒计时
- 新增 E/F 方向键作为核心辅助控件

### 硬件输入体系

| 输入 | 类型 | 说明 |
|:----:|------|------|
| **A** | 按键（开关机） | 长按 2s 开机 / 长按 3s 关机，短按无功能（防误触）。独立于模式体系。 |
| **B** | 按键（模式切换） | 短按循环切换模式，SETTINGS 内短按=返回 |
| **C** | 按键 | 模式相关主操作（确认/开始/录音等） |
| **D** | 按键 | 模式相关副操作（暂停/返回/标记完成等） |
| **E** | 按键 | 上 / 左 / 减 / 上一页 |
| **F** | 按键 | 下 / 右 / 加 / 下一页 |

E 和 F 配对使用，负责列表上下选择、数值加减、文字滚动翻页等方向操作。

每个按键按下都会发出提示音/闪灯一下

### 按键映射总表

B键--单击切换下一个模式，双击回到chat-robot模式，长按进入设置页

|      模式      | C 键                                 | D 键                    | E 键             | F 键             | 特殊                         |
| :------------: | ------------------------------------ | ----------------------- | ---------------- | ---------------- | ---------------------------- |
| **CHAT-ROBOT** | 短按：切表情 / 回复态：上一页        | 回复态：返回表情包      | 回复态：上滚文字 | 回复态：下滚文字 | **长按 C**：语音输入         |

| **COUNTDOWN**  | **开始** 倒计时                      | **暂停/继续**（运行中） | **时间 -1 分钟** | **时间 +1 分钟** | **双击 D**：重置             |
|    **TODO**    | **查看详情/开始任务** → 跳 COUNTDOWN | **标记完成**/取消完成   | **上移**选择任务 | **下移**选择任务 | 开始任务时自动带入预估时长   |
|  **WEATHER**   | 今日详情页                           | 预报页                  | 上翻预报天       | 下翻预报天       | —                            |
|  **SETTINGS**  | **确认**                             | **返回**                | **上移**菜单项   | **下移**菜单项   | 长按 C 无法从此进入 SETTINGS |

### 切换方式汇总

| 触发方式 | 操作 | 说明 |
|----------|------|------|
| 开机 | 长按 A（2s） | 开机动画结束 → CHAT-ROBOT |
| 关机 | 长按 A（3s） | 确认后关机 / 10s 无操作自动休眠 |
| 按键 B 短按 | 循环切换模式 | CHAT-ROBOT→CLOCK→COUNTDOWN→TODO→WEATHER→CHAT-ROBOT（SETTINGS 不参与） |
| 按键 C 长按（任意模式） | → SETTINGS | 进入 SETTINGS |
| 按键 B（SETTINGS 内） | → CHAT-ROBOT | 退出 SETTINGS，回到 CHAT-ROBOT |
| TODO 内启动任务 | → COUNTDOWN | 自动带入任务关联时长 |
| MQTT 远程 | 小程序切模式 | `{"action":"switch","target":"chat-robot/clock/countdown/todo/weather"}` |
| 超时返回 | → CHAT-ROBOT | 非 CHAT-ROBOT 模式超过设定时间（默认30s）无操作 → 回 CHAT-ROBOT（COUNTDOWN 运行中除外） |

**分区域定义**：

**日期区**（y=40~50，10px 高）：
- 格式 `YYYY-MM-DD 星期X`，居中

**信息摘要行**（y=52~62，10px 高）：
- 格式 `{天气图标} {温度}°C  │  待办 {N}项`
- 文本超宽时水平 marquee 滚动

**说明**：CLOCK 模式是纯时钟展示。C 键弹出任务提醒浮层，D 键快捷跳转到 TODO 模式。

**COUNTDOWN 模式交互**：

| 操作 | 功能 |
|------|------|
| **E / F 键** | 空闲态：E -1 分钟，F +1 分钟，范围 1-120 分钟 |
| **E + F 同时按** | 空闲态：快速切换预设时长（15→25→45→60→循环） |
| **C 键** | 空闲态：开始倒计时 / 完成态：再来一个 |
| **D 键** | 运行中：暂停 / 继续 |

| **C 长按(2s)** | 运行中：放弃当前倒计时（二次确认） |

- 宽 120px，高 4px，位于 y=38
- 外框 + 内部填充，实时更新
- 最后 1 分钟：进度条闪烁（500ms 周期）
- 休息模式（番茄钟休息阶段）：进度条显示虚线/条纹，状态栏显示鼓励语

**番茄钟模式**：
- 默认专注 25 分钟 + 休息 5 分钟
- 在 SETTINGS 中修改默认时长
- 小程序可远程设置并同步启动

### CHAT-ROBOT（默认中枢模式）

开机动画结束 → 进入 CHAT-ROBOT。超时无操作 → 回到 CHAT-ROBOT。这是灵动岛的脸。

CHAT-ROBOT 包含 4 个子状态，在同一模式内流转：**表情包 → 语音输入 → AI思考 → 显示回复**。

#### 子状态 A：表情包（空闲态）

没有对话时，显示随机表情包。表情每 6~10 秒切换一次。

```
┌──────────────────────────────────┐
│ 🤖 ☁云端      14:36       ▓▓▓▓ │ 状态栏：机器人图标 + AI模式
├──────────────────────────────────┤
│                                  │
│                                  │
│          (◍•ᴗ•◍)                 │ 表情包大字居中
│                                  │
│                                  │
│                                  │
└──────────────────────────────────┘
```

**表情包行为**：
- 使用完整的 8 个基础表情集（见 §1.4），随机循环播放
- 眨眼动画：每 3 秒一次（闭眼 100ms）
- 呼吸浮动：±1px 垂直微移，周期 2 秒
- 切换过渡：淡出→弹入，200ms
- 按 C 短按：手动切换下一个表情
- 收到通知/任务/消息时：中断当前表情，播放事件表情 3 秒后恢复

#### 子状态 B：语音输入（长按 C 键触发）

```
┌──────────────────────────────────┐
│ 🤖 ☁云端 ●REC 14:36       ▓▓▓▓ │
├──────────────────────────────────┤
│                                  │
│          ┌──────────┐            │
│          │  ◉◉◉    │            │ 麦克风图标 + 声波弧线
│          │ ◉  ◉  ◉ │            │
│          │  聆听中…  │            │
│          └──────────┘            │
│                                  │
│     ▁▂▃▄▅▆▇█▇▆▅▄▃▂▁            │ 实时音量条
│                                  │
│     松开 C 发送  D 取消          │
└──────────────────────────────────┘
```

**语音输入流程**：
1. 在表情包态长按 C（0.5s）→ 进入语音输入
2. 显示麦克风图标 + 声波动画
3. 音量条实时显示 I2S 采集幅度（8 段柱状，100ms 更新）
4. 录音上限 5 秒，超时自动结束
5. 松开 C → PCM 送百度 ASR → 进入 AI 思考态
6. 按 D：取消录音，回到表情包态

#### 子状态 C：AI 思考（ASR 识别成功后自动进入）

```
┌──────────────────────────────────┐
│ 🤖 ☁云端●THINK 14:36     ▓▓▓▓ │
├──────────────────────────────────┤
│                                  │
│                                  │
│          (｡•ˇ‸ˇ•｡)                │ 思考表情
│                                  │
│          ● ○ ○                  │ 三点加载动画
│        正在思考...               │
│                                  │
│          D:取消等待              │
└──────────────────────────────────┘
```

**思考态动画**：
- 显示"思考"表情
- 三点循环加载：●○○ → ○●○ → ○○●（每帧 400ms）
- AI 返回 → 进入显示回复态
- AI 超时（3秒）→ 显示降级回复 → 回表情包态
- 按 D：取消等待，回表情包态

| 转场 | 动画 | 时长 |

| 通知消失 | 向上滑出 | 200ms |

| 低电量警告 | 电量图标 + 边框闪烁 | 持续（500ms 周期）|
| 进入语音子状态 | 表情切换为"倾听"表情 + 麦克风动画弹出 | 300ms |

### CHAT-ROBOT 表情包动画（空闲态）

```
循环周期 6-10 秒（随机波动）：
  0.0s ─── 表情 A 出现（弹入动画，scale 0.8→1.0，200ms）
  2.0s ─── 眨眼（闭眼帧 100ms）
  3.0s ─── 表情呼吸浮动（±1px 垂直，2s 周期）
  5.0s ─── 眨眼（闭眼帧 100ms）
  6~9s ─── 随机间隔后切换到表情 B → 循环
```

### CHAT-ROBOT 子状态切换动画

**表情包 → 语音输入**：
```
- 当前表情淡出（150ms）
- 麦克风图标弹入放大（scale 0.5→1.0，250ms）
- 音量条从底部滑入（150ms）
```

**语音输入 → AI 思考**：
```
- 麦克风图标缩小淡出（150ms）
- "思考"表情淡入（(｡•ˇ‸ˇ•｡)，200ms）
- 三点加载动画开始（400ms/帧循环）
```

**思考 → 显示回复**：
```
- 思考表情 + 加载动画淡出（150ms）
- 回复文字从底部逐行滑入（每行 100ms 间隔）
```

```
  ↓
小程序标记完成 → MQTT 推送 {type:"task_done", task_id:"xxx"}
  ↓
ESP32 收到 → OLED 更新任务列表 → 显示完成动画
```

## 八、异常状态与容错设计

### 网络异常

| 场景 | OLED 端表现 | 小程序端表现 |
|------|------------|-------------|
| WiFi 断开 | 状态栏 WiFi 图标显示 ✕，顶部滚动"网络已断开" | 设备卡片变灰，显示"离线"，功能禁用 |
| WiFi 恢复 | 自动重连，状态栏恢复，Toast"网络已恢复" | 自动重连 MQTT，恢复在线状态 |
| MQTT 断连 | 状态栏 MQTT 指示灯变红，本地功能正常 | Top Bar 显示"设备同步断开"，本地操作入队列 |
| MQTT 恢复 | 自动重连，队列中的操作批量同步 | 队列操作自动发送 |

### 异常状态处理

```
电量极低（<5%）：
  OLED：全屏闪烁 ⚠ 图标，自动进入省电模式
  小程序：设备卡片红色警告"电量极低，请立即充电"

AI API 不可用：
  OLED：显示"AI服务暂时不可用"，提供降级预设回复
  小程序：Toast"AI服务异常，已切换到本地回复模式"

OTA 更新：
  OLED：显示"固件更新中..."+ 进度条，重启后恢复
  小程序：显示更新进度，完成后提示
```
