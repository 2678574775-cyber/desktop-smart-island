# 桌面智能灵动岛 — 手机端App设计 V1.0

> 版本：v1.0 | 日期：2026-05-30 | 角色：数字孪生 + 统筹管家

---

## 一、产品定位

### 核心角色关系

```
桌面小狗（硬件 ESP32-C3） ← 主战场 · 高频交互
    ├── 语音对话、表情包互动
    ├── 番茄钟物理控制（按键启动/暂停）
    └── OLED表情反馈
   
手机端App ← 数字孪生 · 统筹管家 · 数据中枢
    ├── 全量记录保存（聊天历史、任务统计）
    ├── 远程同步操作（任务创建/编辑、番茄钟开关）
    ├── AI文字对话（设备端仅支持语音补充）
    └── 宠物角色存在（状态指示、情感维系）
```

**一句话描述：** 打开App，第一眼看到的是你的"桌面小狗"——它现在在干嘛？电量多少？今天完成了什么？然后你可以用它管理任务、查看AI对话记录、远程控制番茄钟。

## 三、导航架构

### 总体结构：中心式 Tab + 子页返回

```
┌──────────┐     ┌──────────┐
│  对话页   │◄────┤          │
└──────────┘     │          │       ┌──────────┐
                 │  主页(Tab) ├─────→│  设置页   │
┌──────────┐     │          │       └──────────┘
│  任务页   │◄────┤          │
└──────────┘     └──────────┘
         ↑
         底部 4Tab 导航
```

**四个 Tab：**

| Tab | 页面 | 功能 |
|-----|------|------|
| 🏠 **主页** | 宠物概览 | 宠物状态、今日三指标、动态摘要 |
| 📋 **任务** | 任务管理 | Todo CRUD、优先级、同步到设备 |
| 💬 **对话** | AI对话记录 | 聊天记录浏览、文字对话、语音对话 |
| ⚙️ **设置** | 设备设置 | WiFi配网、设备绑定、功能配置 |

**注意：** 没有独立的番茄钟 Tab。番茄钟作为主页的一部分或从任务页快捷进入。

#### 细节说明

**宠物展示区：**

- 圆形区域，220px直径
- 播放线条小狗视频素材
- 下方贴状态标签："✨ 开心中~" / "🛌 睡觉了..." / "💭 正在思考..."

- 一行三等分，圆角白色卡片

**点击宠物：**
- 短按：触发一个随机反应动画（摇尾巴/跳一下）
- 长按：不触发功能，纯娱乐互动

## 六、技术栈

### 6.1 框架选型

| 层 | 技术 | 说明 |
|----|------|------|
| **前端框架** | Flutter（Dart） | Android原生App，后续可扩展iOS |
| **后端服务** | Cloudflare Workers | 轻量Serverless，API Key管理/对话记录持久化/请求中转 |
| **MQTT Broker** | EMQX Cloud（已有） | 设备与App实时双向通信 |
| **视频播放** | Flutter `video_player` | 宠物MP4循环播放 + 状态切换 |
| **HTTP 客户端** | `dio` 或 `http` | 调用智谱AI / 和风天气 / 百度ASR 等API |
| **本地存储** | `sqflite` / `shared_preferences` | 对话记录本地缓存、任务离线存储、用户设置 |
| **状态管理** | `provider` 或 `riverpod` | 全局设备状态、任务列表、对话历史管理 |

### 6.3 Cloudflare Workers 职责

```
Workers 路由设计：
  POST /api/chat          → 智谱AI 对话代理（流式响应支持）
  POST /api/chat/push     → 推送对话内容到设备（MQTT）
  GET  /api/weather       → 和风天气代理
  GET  /api/chat/history  → 对话历史（Cloudflare D1）
  POST /api/chat/history  → 保存对话记录
  GET  /api/device/status  → 设备状态查询
```

### 6.6 宠物视频播放策略

- 4个核心MP4：开心/正常（循环）、眨眼（触发式100ms叠加）、思考（循环）、睡觉（循环）
- 状态切换：当前视频 `AnimatedOpacity` 淡出 → 切换源 → 新视频淡入（300ms 过渡）
- 空闲态（开心）：无缝循环播放，周期性插入眨眼动画（每3秒）
- 省电优化：非主页 Tab 时暂停视频播放
- 预加载：App启动时 `precache` 所有宠物视频到内存

## 七、双端同步协议

### MQTT主题

| 主题 | 方向 | 说明 |
|------|------|------|
| `device/{id}/status` | ESP32 → App | 设备在线/电量/当前状态 |
| `device/{id}/task/add` | App → ESP32 | 新增任务 |
| `device/{id}/task/list` | ↔ | 任务列表同步 |
| `device/{id}/task/done` | ↔ | 任务完成标记 |
| `device/{id}/pomodoro/start` | ↔ | 番茄钟启动/暂停 |
| `device/{id}/pomodoro/status` | ESP32 → App | 番茄钟进度 |
| `device/{id}/message/chat` | App → ESP32 | AI对话推送到设备 |
| `device/{id}/chat/history` | ESP32 → App | AI对话历史同步 |

### 数据格式

```json
// 设备状态上报
{
  "battery": 85,
  "state": "idle",           // idle | voice | thinking | pomodoro | sleeping
  "pomodoro_remain": 1832,   // 剩余秒数
  "wifi_rssi": -45,
  "pet_mood": "happy"        // happy | listening | thinking | sleepy
}

// 任务同步
{
  "id": "t_001",
  "title": "完成高数作业",
  "deadline": "2026-05-22T18:00:00",
  "priority": 1,              // 1=高 2=中 3=低
  "estimated_minutes": 45,
  "notes": "第3章课后习题1-20",
  "status": "pending",        // pending | done
  "pushed_to_device": true
}
```

## 九、与硬件端的对应关系

| App功能 | 硬件OLED端对应 | 同步方式 |
|---------|---------------|---------|
| 宠物状态映射 | 表情包系统 + 模式流转 | MQTT状态上报 |

| 设备设置 | SETTINGS模式 | MQTT配置同步 |
| 数据统计 | 硬件端不可见 | App本地/云端存储 |
