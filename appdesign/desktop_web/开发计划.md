# 桌面智能灵动岛 — 网页端开发计划 V1

> 基于 App设计 V1.md | 技术栈：HTML + CSS + JS（原生）| 平台：桌面浏览器

---

## 一、产品定位

对标 Flutter App 的四大模块（主页、任务、对话、设置），在桌面浏览器中运行。
- **独立运行**：内置 Mock 数据，不依赖硬件设备
- **可扩展**：后期可选接入 MQTT 连接真实 ESP32 设备
- **宽屏优先**：1920×1080 典型分辨率，响应式适配

## 三、技术栈

| 层 | 方案 | 说明 |
|----|------|------|
| 页面结构 | HTML5 | 单文件 SPA，`<section>` 管理页签 |
| 样式 | CSS3 | CSS 变量 + Flexbox/Grid + Keyframe 动画 |
| 逻辑 | 原生 JS (ES6+) | 无框架依赖，Event Delegation + DOM 操作 |
| 数据 | LocalStorage | 任务/对话持久化，页面刷新不丢失 |
| 动画 | CSS Animation + JS | 宠物呼吸、眨眼、气泡弹出、Tab 切换 |
