# 桌面智能灵动岛 App — 开发计划 V1

> 基于 App设计 V1.md | 技术栈：Flutter + Dart (Android) | 策略：前端先行，后端后补

---

## 策略

```
前端先行 → Mock数据驱动 → UI全部可用 → 再接真实服务层
```

- **第一优先级**：Flutter UI 全部做完，用本地 Mock 数据跑通所有页面
- **第二优先级**：接入 MQTT + API 真实数据源
- **第三优先级**：Cloudflare Workers 后端

## 阶段一：工程搭建 + 主题配置

### 1.1 创建 Flutter 项目

```bash
flutter create --org com.desktoppet desktop_pet_app
cd desktop_pet_app
```

### 1.2 配置 `pubspec.yaml` — 先只用 UI 相关依赖

```yaml
dependencies:
  flutter:
    sdk: flutter
  video_player: ^2.8.0        # 宠物MP4播放
  provider: ^6.1.0            # 状态管理
  shared_preferences: ^2.2.0  # 简单键值存储
  intl: ^0.19.0               # 日期格式化
  flutter_animate: ^4.5.0     # 动画辅助（可选）
```

> MQTT / dio / sqflite 等真实服务依赖在阶段八再加。

### 1.3 `lib/theme/` — 全局视觉常量

| 文件 | 内容 |
|------|------|
| `colors.dart` | `AppColors.primary` / `primaryLight` / `bg` / `card` / `textPrimary` 等 |
| `typography.dart` | `AppText.xs(20rpx)` / `sm(24)` / `base(28)` / `lg(32)` / `xl(36)` |
| `theme.dart` | `AppTheme.light()` → `ThemeData`，配置 AppBar/Card/Input/BottomNavBar 默认样式 |

### 1.4 `lib/main.dart` — 入口

- `MaterialApp` → `theme: AppTheme.light()`
- `MultiProvider` 挂载 provider
- 初始路由 → `OpeningScreen`

### 1.5 开幕动画屏 (`screens/opening_screen.dart`)

- 全屏播放 `assets/videos/opening.mp4`
- 播放完成 → `Navigator.pushReplacement` → `MainScreen`
- 用 `shared_preferences` 标记"已播放"，热启动跳过

## 阶段二：数据模型 + Mock 数据

### 2.1 `lib/models/` — 三个数据类

**`device_state.dart`**
```dart
class DeviceState {
  final bool online;
  final int battery;
  final String state;         // idle | voice | thinking | pomodoro | sleeping
  final int pomodoroRemain;
  final String petMood;       // happy | listening | thinking | sleepy
  // fromJson / toJson
}
```

**`task.dart`**
```dart
class Task {
  final String id;
  final String title;
  final DateTime deadline;
  final int priority;         // 1=高 2=中 3=低
  final int? estimatedMinutes;
  final String? notes;
  final bool done;
  // fromJson / toJson
}
```

**`chat_message.dart`**
```dart
class ChatMessage {
  final String id;
  final String role;          // 'user' | 'assistant'
  final String content;
  final DateTime timestamp;
  // fromJson / toJson
}
```

### 2.2 `lib/mock/` — Mock 数据文件

| 文件 | 内容 |
|------|------|
| `mock_device.dart` | 一份静态 `DeviceState`，模拟在线/85%电量/开心状态 |
| `mock_tasks.dart` | 5条示例任务（3条待办 + 2条已完成），覆盖不同优先级 |
| `mock_chat.dart` | 5条示例对话记录 |

### 2.3 `lib/providers/` — 三个轻量状态管理器（先读 Mock）

**`device_provider.dart`**
- 初始化时加载 `mockDeviceState`
- 暴露 `DeviceState? current`
- `ChangeNotifier`

**`task_provider.dart`**
- 初始化时加载 `mockTasks`
- `add(Task)` / `toggleDone(id)` / `delete(id)` / `filterBy(priority)`
- 操作只改内存中的 list，暂不持久化
- `ChangeNotifier`

**`chat_provider.dart`**
- 初始化时加载 `mockChatMessages`
- `sendMessage(text)` → 先用延时模拟 AI 回复（1.5s 后插入一条假回复）
- `pushToDevice(messageId)` → 先 Toast 提示"已推送"
- `ChangeNotifier`

## 阶段三：通用组件库

### 3.1 `widgets/pet_display.dart` — 宠物视频播放器

- 圆形裁切（`ClipOval`），直径 220px
- `VideoPlayerController` 循环播放
- 参数：`String videoAsset` / `String statusLabel`
- 视频源先只用一个 `pet_happy.mp4`，后续阶段再接状态切换
- 点击 → `onTap` 回调（随机反应动画）

### 3.2 `widgets/indicator_card.dart` — 指标卡片

- 参数：`String title` / `String value` / `Color? color` / `VoidCallback? onTap`
- 圆角白色卡片，固定宽度三等分适配
- 大号数字在上、小号说明在下

### 3.3 `widgets/day_summary.dart` — 今日动态

- 接收 `List<SummaryItem>`（时间 + 描述）
- 时间线样式
- 超过 5 条折叠

### 3.4 `widgets/task_item.dart` — 任务列表项

- 显示：圆圈 + 标题 + 优先级标签 + 截止时间
- 点击 → `onTap`
- 左滑 → `onDelete`
- 参数：`Task task` + 回调

### 3.5 `widgets/chat_bubble.dart` — 对话气泡

- 参数：`ChatMessage message`
- AI消息：左对齐、白底
- 用户消息：右对齐、暖橙底白字
- AI消息下方可选"推送到设备"按钮

## 阶段八：对接真实服务层

> 此时前端所有页面已可完整运行。开始替换 Mock 为真实数据源。

### 8.1 添加新依赖

```yaml
dependencies:
  mqtt_client: ^10.0.0        # MQTT
  dio: ^5.4.0                 # HTTP
  sqflite: ^2.3.0             # SQLite 本地库
  path_provider: ^2.1.0
```

### 8.2 `services/mqtt_service.dart`

- 连接 EMQX Cloud
- 订阅 / 发布设备主题
- `DeviceProvider.updateFromMqtt()` 回调

### 8.3 `services/api_service.dart`

- 对接 Cloudflare Workers（或直连智谱AI / 和风天气）
- AI对话 / 天气 / 历史记录

### 8.4 `services/storage_service.dart`

- `shared_preferences`：设置 / 设备绑定
- `sqflite`：任务 + 对话本地缓存

### 8.5 改造 Provider

- `TaskProvider`：操作同步到 SQLite + MQTT
- `ChatProvider`：HTTP 请求替换模拟回复 + SQLite 缓存历史
- `DeviceProvider`：MQTT 实时更新替换 Mock

## 阶段九：Cloudflare Workers 后端

### 9.1 项目结构

```
backend/
├── wrangler.toml
├── schema.sql                 # D1 表结构
└── src/
    ├── index.ts               # 路由分发
    ├── handlers/
    │   ├── chat.ts            # AI对话代理
    │   ├── chatPush.ts        # 推送到设备MQTT
    │   └── weather.ts         # 天气代理
    └── utils/
        └── db.ts              # D1操作
```

### 9.2 D1 表

```sql
CREATE TABLE chat_history (
  id TEXT PRIMARY KEY,
  device_id TEXT NOT NULL,
  role TEXT NOT NULL,
  content TEXT NOT NULL,
  ai_mode TEXT,
  pushed INTEGER DEFAULT 0,
  created_at INTEGER NOT NULL
);
```

### 9.3 路由

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/chat` | AI对话代理 |
| POST | `/api/chat/push` | 推送消息到设备 MQTT |
| GET | `/api/chat/history` | 对话历史 |
| GET | `/api/weather` | 天气代理 |

```
阶段一（工程+主题）
  → 阶段二（模型+Mock）
    → 阶段三（通用组件）
      → 阶段四 ★ 主页
      → 阶段五   任务页

每阶段完成后即可独立验证。
```
