I2S 同一时刻只能配置为 RX 或 TX：
  • 录音: i2sInitRecord() 配置 RX → GPIO20 LOW 关断功放防自激啸叫
  • 播放: i2sDeinit() → i2sInitPlay() 配置 TX → GPIO20 HIGH 开功放
  • 录音 32bit 模式 (INMP441 24bit 置高24位) · 播放 16bit 模式
  • 功放 VIN 接电池 3.7V 直供 (峰值 0.5A, 不走 LDO)

十一、关键技术难点与解决方案
ESP32-C3 无 DAC
无法接模拟功放 (PAM8403)
→
选型 MAX98357A I2S 数字功放
纯数字输入 · 与 INMP441 共用 BCLK/LRC · 软件 i2sInitRecord/i2sInitPlay 动态切换 · 效率 92%
麦克风与功放冲突
共用 I2S 总线不能同时收发
→
GPIO20 控制功放关断 + 软件互斥
录音前 GPIO20 LOW 关断防自激 · I2S 先卸载再重新初始化反向 · 录音 32bit / 播放 16bit
GPIO 资源紧缺
仅 11 可用 IO · GPIO0 硬件损坏
→
4 键直连 + INPUT_PULLUP 省电阻 + ADC 测电量
GPIO0 损坏→改为电池 ADC · 按键全用内部上拉 · 功放 SD 用 GPIO20 控制 · 原设计 6 键 74HC138D 方案因 GPIO0 损坏而搁置
ESP32-C3 RAM 有限
~400KB SRAM
→
模块化加载 + 录音 buffer 限制
按需初始化 · 录音限 3s · config.h 统一管理全局状态避免重复分配 · 软件 WDT 防死锁
答辩现场网络风险
WiFi 不稳 / API 超额
→
本地 Mosquitto + PC 热点 + API 备份
MQTT 不走外网 · PC 热点方案 · 智谱 API 多 Key 备份 · 预设回复兜底
