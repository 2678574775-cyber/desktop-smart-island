# 模块一：整体概述 — 桌面智能灵动岛

> 生成日期：2026-06-07 | 依据：设计文档 + 实际代码交叉对比

---

## 一、项目定位

基于 **ESP32-C3 SuperMini** 驱动的桌面 OLED 智能终端，集 AI 语音对话、番茄钟任务管理、MQTT 多端联动于一身的电子宠物产品。

**一句话描述**：一个放在桌面的小型 OLED 屏幕小狗，你可以跟它语音聊天，它帮你计时番茄钟、同步待办事项，Web 端和手机端都可以控制它。

### 4.3 6 种应用模式

| 模式 | 枚举值 | 定位 | 实际功能 |
|------|:------:|------|---------|
| **CHAT-ROBOT** | 0 | 默认中枢 | A 长按录音→ASR→MQTT 发 Web AI→OLED 文字回复。40 行历史缓存，B/C 翻页 |
| **CLOCK** | 1 | 大字时钟 | HH:MM 闪烁冒号 + 日期星期 + 硬编码摘要 |
| **COUNTDOWN** | 2 | 倒计时/番茄钟 | A/B ±5min 连按加速，C 开始/B 暂停/BB 取消，进度条+结束闪，番茄钟自动休息 |
| **TODO** | 3 | 待办任务 | LIST/DETAIL 两态，任务来自 MQTT，A 标完成回传 MQTT，B 跳倒计时 |
| **WEATHER** | 4 | 天气 | TODAY+FORECAST 两页，数据硬编码 |
| **SETTINGS** | 5 | 系统设置 | 7 项菜单：WiFi/亮度(写SSD1306寄存器)/睡眠(NVS持久化)/AI模式 |

**模式切换**：
- D 键短按：循环切换 CHAT-ROBOT → CLOCK → TODO → ...
- D 键**双击**：配对切换 CLOCK↔WEATHER、TODO↔COUNTDOWN
- D 键**长按 2s**：进入 SETTINGS
- 30s 无操作：自动回 CHAT-ROBOT（倒计时运行中除外）

### 4.4 按键体系（4 键，非设计中 6 键）

| 按键 | GPIO | 全局角色 | 各模式角色 |
|:----:|:----:|---------|-----------|
| A | GPIO2 | CHAT-ROBOT 录音，COUNTDOWN -5min，TODO 下一个 | 方向: 上/下/± |
| B | GPIO4 | 副操作: 暂停/返回 | 暂停/返回/翻页 |
| C | GPIO3 | 主操作: 确认/开始/进入 | 开始/确认/进入 |
| D | GPIO1 | **模式切换中枢** (短按/长按/双击) | 全局 |

> **设计 vs 实际差异**：设计文档定义 6 键 (A=电源, B=模式, C=主操作, D=副操作, E/F=方向)，实际简化为 4 键 (A=方向, B=副操作, C=主操作, D=模式中枢)。GPIO0 (原 E 键) 硬件损坏，改为电池 ADC 检测。

### 7.4 I2S 总线共用方案

INMP441（录音）和 MAX98357A（播放）**共用 BCLK/LRC**，两者互斥切换：录音时 `i2sInitRecord()` 配置 RX 模式，播放时 `i2sInitPlay()` 配置 TX 模式。

```
            ESP32-C3                 MAX98357A           INMP441
            ────────                ──────────          ────────
  GPIO5 ──→ BCLK ──────────┬────→ BCLK         ┌────→ SCK
  GPIO6 ──→ LRC  ──────────┼────→ LRC          ├────→ WS
  GPIO7 ──→ DIN  ──────────┼────→ DIN          │
  GPIO10 ←── DOUT ─────────┼────────────────── └──── SD
                            │
                    电源与配置:
                    VIN  → 电池 3.7V (直供)
                    GND  → GND
                    GAIN → GND (12dB)
                    SD   → GPIO20 (关断控制)
                    + /- → 喇叭 4Ω 3W

                    VDD  → 3.3V (禁止 5V!)
                    GND  → GND
                    L/R  → GND (左声道, 禁止悬空)
```

**软件层面**：`i2s_hal.cpp` 提供 `i2sInitRecord()`（RX 配置）、`i2sInitPlay()`/`i2sInitPlayAt(int sampleRate)`（TX 配置）、`i2sDeinit()`（卸载驱动）。录音和播放之间需要先卸载再重新初始化。录音用 32bit 模式（INMP441 输出 24bit 置于高 24 位），播放用 16bit 模式。

### 7.5 电源架构

```
USB 5V → TP4056 充电模块 → 14250 锂电池 (3.7V, 300mAh)
                                │
            ┌───────────────────┴───────────────┐
            │ 3.7V 直供 (大电流)                 │ 3.3V 稳压 (小电流)
            ▼                                   ▼
       MAX98357A VIN                    AMS1117-3.3V LDO
       (功放功率部分)                         │
            │                   ┌──────────────┼──────────────┐
            ▼                   ▼              ▼              ▼
          喇叭 3W            ESP32-C3        OLED          INMP441
                            SuperMini       3.3V           3.3V
                             3.3V
```

| 供电对象 | 供电电压 | 来源 | 电流需求 |
|----------|----------|------|----------|
| ESP32-C3 SuperMini | 3.3V | AMS1117 LDO | ~80mA (平均) |
| OLED SSD1306 | 3.3V | AMS1117 LDO | ~20mA |
| INMP441 麦克风 | 3.3V | AMS1117 LDO | ~1.4mA |
| MAX98357A 控制部分 | 3.3V | AMS1117 LDO | ~2mA |
| MAX98357A 功放部分 | 3.7V | **电池直供** | 峰值 ~500mA |

**设计要点**：功放的峰值电流远大于其他元件，因此 MAX98357A 的 VIN 直接接电池 3.7V，不经过 AMS1117 LDO（LDO 通常最大输出电流仅 500mA-800mA，功放+ESP32 同时工作时可能不足）。功放的控制逻辑部分由 3.3V 供电。

### 7.6 按键电路

4 键直连 GPIO，`INPUT_PULLUP` 内部上拉（GPIO2 除外，用 `INPUT` 模式因 Strapping 引脚）：

```
GPIO ─┬─ [按键] ─ GND
      │
      └─ [ESP32 内部上拉 ~45kΩ] ─ 3.3V

按下 = LOW，松手 = HIGH
```

| 按键 | GPIO | 去抖方案 | 支持事件 |
|:----:|:----:|----------|----------|
| A | GPIO2 | 连续 8 次同值确认 (~8ms) | 短按、长按 (1s，触发录音) |
| B | GPIO4 | 同上 | 短按、双击 (500ms 窗口) |
| C | GPIO3 | 同上 | 短按 |
| D | GPIO1 | 同上 | 短按(切模式)、双击(配对联调)、长按(2s，进设置) |

> 去抖精度：主循环 1kHz 轮询，8 次同值确认 ≈ 8ms 去抖窗口，按下到确认延迟 < 12ms。

### 7.7 电池检测电路

GPIO0 经分压电阻接入电池：

```
V_bat (3.7V ~ 4.2V)
  │
  ├─ R1 (100kΩ) ─┐
  │              ├──→ GPIO0 (ADC1_CH0)
  ├─ R2 (100kΩ) ─┘
  │
  ┴ GND

V_adc = V_bat × R2/(R1+R2) = V_bat × 0.5
V_bat = V_adc × (R1+R2)/R2 = V_adc × 2.0
```

`batt_hal.cpp` 实现：8 次 ADC 采样取平均 → 滤波 → 映射到 3.3V-4.2V → 0-100%。读取间隔 10s（`BATT_READ_MS`），仅在状态栏电池图标更新时触发，不参与高频循环。

### 7.8 硬件注意事项

1. **INMP441 供电**：⚠️ **绝对禁止接 5V**，只能使用 3.3V。L/R 引脚必须接死（GND 或 3.3V），不能悬空。
2. **Strapping 引脚**：GPIO2 为 Strapping 引脚，开机时请勿按住按键 A，否则可能影响启动。代码中 GPIO2 使用 `INPUT` 而非 `INPUT_PULLUP`。
3. **I2S 信号完整性**：I2S 连线尽量短于 5cm，与 WiFi 天线保持距离。
4. **功放与麦克风不能同时工作**：两者共用 BCLK/LRC，I2S 驱动同一时刻只能配置为 RX 或 TX。录音前功放先关断（`AMP_SD_PIN LOW`）防止自激啸叫。
5. **GPIO 资源紧张**：11 个可用 GPIO 已全部使用，无剩余。原设计的 5 按键因 GPIO0 硬件损坏改为电池 ADC，因此实际只有 4 按键。
6. **天线净空**：ESP32-C3 板载陶瓷天线一侧需要保持净空，避免金属物体遮挡。
