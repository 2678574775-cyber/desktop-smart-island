五、74HC138D 按键矩阵
对应 PPT 第 11 页 · 4 脚 → 6 键
74HC138D (3-8 译码器)
74HC138 引脚连接说明
A (1脚)GPIO0地址 LSB
B (2脚)GPIO1地址
C (3脚)GPIO2地址 MSB
G2A (4脚)GND使能 低有效
G2B (5脚)GND使能 低有效
G1 (6脚)+3V3使能 高有效
VCC (16脚)+3V3供电
GND (8脚)GND地
按键接线 & 扫描
Y 输出按键地址 CBA功能
Y0 (15脚)SW1000模式切换
Y1 (14脚)SW2001音量+
Y2 (13脚)SW3010音量-
Y3 (12脚)SW4011播放/暂停
Y4 (11脚)SW5100上一曲
Y5 (10脚)SW6101下一曲
KEY_IN (GPIO3) ← 6 按键公共端 + 10kΩ 上拉 +3V3
0=按下   1=未按

扫描逻辑（伪代码）

for (int i = 0; i < 6; i++) {
  GPIO0 = i & 1;   GPIO1 = i & 2;   GPIO2 = i & 4;   // 地址
  delay_us(10);   // 等待 74HC138 稳定
  if (!GPIO3) return i;   // 按键 i 被按下
}
return -1; // 无按键
