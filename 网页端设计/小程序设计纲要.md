# 桌面智能灵动岛 — 微信小程序设计纲要

> 版本：v1.0 | 日期：2026-05-23 | 基于界面与功能设计 v1.0 + 网页设计大纲 v1.0

---

## 一、设计概述

### 1.1 项目定位

微信小程序作为桌面智能灵动岛的**数字孪生终端**，以萌宠陪伴为核心体验，将硬件设备的状态映射为卡通小狗形象，提供任务管理、AI对话、设备控制等功能，与ESP32-C3硬件设备通过MQTT协议实时同步。

### 1.2 设计目标

- **情感连接**：通过数字孪生小狗建立用户与设备的情感纽带
- **简洁高效**：中心辐射式导航，核心功能一键触达
- **实时反馈**：设备状态实时映射到宠物形象，操作结果即时可见
- **萌趣体验**：暖色调、圆润造型、趣味动画，养宠App般的体验

### 1.3 页面清单

| 页面 | 功能定位 | 优先级 |
|------|----------|--------|
| 主页（宠物页） | 数字孪生小狗 + 设备状态映射 + 导航枢纽 | P0 |
| 待办页 | Todo任务管理（增删改查 + 同步） | P0 |
| 对话页 | AI对话（文字输入 + 语音输入） | P1 |
| 设置页 | 设备绑定、WiFi配网、功能设置、关于 | P2 |

### 1.4 导航结构

**中心辐射式导航**：主页为宠物中心，3个气泡入口导向子页面，子页面通过返回按钮回到主页。

```
         ┌─────────┐
         │  待办页  │
         └────▲────┘
              │
┌─────────┐   │   ┌─────────┐
│  对话页  │◄──┴──►│  宠物主页 │◄──► 设置页
└─────────┘       └─────────┘
```

**不使用底部Tab Bar**，采用气泡环绕导航 + 页面返回的方式。

## 三、页面详细设计

### 3.1 主页（宠物页）

#### 功能定位

数字孪生小狗展示 + 设备状态映射 + 导航枢纽。"一屏感知设备，一键触达功能。"

#### 布局

```
┌──────────────────────────────┐
│  桌面灵动岛       🔋85%  📶   │  顶部状态栏（轻量）
├──────────────────────────────┤
│                              │
│        💬 对话               │  气泡入口（浮动动画）
│                              │
│            🐕                │  卡通小狗（线条小狗+电子宠物风）
│                              │
│     📋 待办        ⚙ 设置    │  气泡入口（浮动动画）
│                              │
│  ┌────────────────────────┐  │
│  │ 🐾 心情：开心          │  │  宠物状态卡片
│  │ 🔋 电量 85%   📶 良好  │  │  设备状态映射
│  │ 🍅 专注中 18:32        │  │  运行中任务（如有）
│  └────────────────────────┘  │
│                              │
│  💡 长按小狗开始语音对话      │  底部提示
└──────────────────────────────┘
```

#### 宠物形象设计

**风格**：线条小狗（参考网图"线条小狗"maltese）+ 电子宠物风格融合

**形象特征**：
- 简洁线条勾勒的可爱小狗
- 白色/浅色线条 + 暖橙色填充点缀
- 大眼睛、圆耳朵、短腿、翘尾巴
- 表情变化通过眼睛和嘴巴实现
- 整体风格：简约、可爱、有辨识度

**开幕动画**：
- 小程序启动时播放开幕动画（视频格式，由外部提供）
- 动画结束后进入主页，小狗以弹入动画出现

#### 宠物状态映射

| 设备状态 | 小狗表现 | 动画 |
|---------|---------|------|
| 空闲/正常 | 随机表情（开心/眨眼/撒娇），尾巴轻摇 | 呼吸浮动+眨眼 |
| 低电量（<20%）| 垂耳朵、困倦表情、偶尔打哈欠 | 缓慢浮动 |
| 专注模式 | 戴小眼镜、认真表情、前爪放桌上 | 轻微点头 |
| 语音录入 | 竖起耳朵、歪头倾听 | 声波动画环绕 |
| AI思考 | 挠头、思考气泡 | 三点加载动画 |
| 充电中 | 趴着休息、闭眼微笑 | 闪电标记闪烁 |
| 离线 | 灰色调、闭眼睡觉 | Zzz动画 |
| 新任务到达 | 惊讶表情、竖耳朵 | 弹跳反应 |
| 任务完成 | 开心跳跃、摇尾巴 | 庆祝动画 |

#### 交互方式

| 操作 | 触发方式 | 反馈 |
|------|---------|------|
| 点击小狗 | 短按 | 随机反应（摇尾巴/开心跳/撒娇/汪一声） |
| 长按小狗 | 长按0.5s | 进入语音输入模式（耳朵竖起 + 声波动画） |
| 气泡入口 | 点击气泡 | 进入对应子页面（待办/对话/设置） |
| 下拉刷新 | 下拉手势 | 刷新设备状态 |
| 宠物状态卡片 | 点击 | 展开详细设备信息 |

#### 气泡导航设计

3个浮动气泡环绕小狗，带有轻微浮动动画：

```
气泡样式：
  - 圆形胶囊形状
  - 暖橙渐变背景
  - 白色图标+文字
  - 轻微阴影
  - 浮动动画（上下飘动，1.5秒周期，错开相位）

气泡位置：
  - 对话：左上方
  - 待办：左下方
  - 设置：右下方
```

#### 离线状态

设备离线时：
- 小狗变为灰色调、闭眼睡觉
- 气泡入口可点击但显示"设备离线"提示
- 状态卡片显示"设备离线，请检查连接"

#### 交互说明

2. **标记完成**：点击任务左侧圆圈，同步到设备
3. **编辑任务**：点击任务卡片或"编辑"按钮
4. **删除任务**：左滑任务卡片露出删除按钮

6. **同步状态**：已推送🟢 / 未推送🟡 / 推送失败🔴（可重试）
7. **到期提醒**：截止前30分钟双端提醒
8. **返回主页**：左上角返回按钮

#### 同步逻辑

```
新建任务 → 本地存储 → MQTT推送 → ESP32收到 → OLED弹通知
标记完成 → MQTT推送 → ESP32收到 → OLED更新列表+完成动画
ESP32本地完成 → MQTT推送 → 小程序列表更新
```

## 五、开幕动画

### 5.1 动画说明

小程序启动时播放开幕动画，展示灵动岛品牌形象。

- **格式**：视频（由外部提供，可替换）
- **时长**：约2-3秒
- **内容**：品牌logo/灵动岛形象出场动画
- **过渡**：动画结束后淡入主页，小狗以弹入动画出现

### 5.2 实现方式

- 使用`<video>`组件播放开幕动画视频
- 播放结束后自动跳转到主页
- 仅首次启动或冷启动时播放，热启动不重复播放
- 可在设置中关闭开幕动画
