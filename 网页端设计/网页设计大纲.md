# 桌面智能灵动岛 - 小程序设计大纲

> 版本：v1.0 | 日期：2026-05-21 | 对应技术方案角色D

---

## 一、设计概述

### 1.1 项目定位
微信小程序作为桌面智能灵动岛的远程控制终端，提供任务管理、AI对话、设备控制等功能，与ESP32-C3硬件设备通过MQTT协议实时同步。

### 1.2 设计目标
- **简洁高效**：核心功能一键触达，减少用户操作层级
- **实时反馈**：设备状态实时同步，操作结果即时可见
- **视觉统一**：采用现代卡片式设计，与硬件OLED显示风格呼应
- **稳定可靠**：弱网环境下仍有良好的用户体验

### 1.3 页面清单

| 页面 | 功能定位 | 优先级 |
|------|----------|--------|
| 首页（设备页） | 设备状态总览 + 快捷操作入口 | P0 |
| 任务页 | Todo任务管理（增删改查 + 同步） | P0 |
| 对话页 | AI对话（文字输入 + 语音输入） | P1 |
| 番茄钟页 | 远程启动/控制番茄钟 | P1 |
| 设置页 | 设备绑定、WiFi配网、关于 | P2 |

```
  按钮：[创建任务]

无设备：
  图标：📡
  标题：未绑定设备
  描述：扫描二维码添加你的桌面灵动岛
  按钮：[扫描添加]

网络错误：
  图标：📶
  标题：网络连接失败
  描述：请检查网络设置后重试
  按钮：[重试]
```
